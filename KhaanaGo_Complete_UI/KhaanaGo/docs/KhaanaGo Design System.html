KhaanaGo Design System
KhaanaGo · Design system v1.0 · Zesty Orange & Charcoal

One system for four apps, built around honest capacity.

Customer app, rider app, vendor portal and admin portal share the same colour, type, spacing and components. This sheet is the reference for Figma, Flutter and React, and for the UI figures in Chapter 2, Section 2.4.

Principles

Four rules that settle most design arguments. Each one comes from a finding in the pilot surveys or a user story in Chapter 2.

Say what the kitchen can doCapacity states (Available, Limited, Full, Paused) are the most consistent colour signal in the product, on customer slots, vendor meters and admin monitors.
Orange asks, charcoal answersOrange marks the one action or selection that matters on a screen. Charcoal carries text, so labels on orange stay readable.
Never colour aloneEvery state pairs its colour with an icon and a word, so the UI works in sunlight, in rain and for colour-blind users.
Same parts, different densityRiders get 64 dp buttons and 20 sp text. Vendors get dense tables. Both draw from the same tokens.

Colour

The four brand colours are fixed. Everything else (tints, text shades, status colours, dark theme) is derived so that each pairing passes WCAG AA, 4.5:1 for text and 3:1 for icons, borders and focus rings.

500 is the brand fill. 700 is the minimum for orange text on cream or white. 400 is the text shade on charcoal and the pressed state of buttons. 100 and 200 are tints for selection.

Typography

Plus Jakarta Sans throughout, the face already used in the project deck. It ships as a Google font, so Flutter and React use the same file. Prices and times use tabular figures so columns line up.

Rider mode scale

  • Body 20/28, buttons 20/28 at weight 800, status line 28/34
  • Minimum text size 16 sp anywhere in the rider app
  • Maximum 3 lines of text per screen while a delivery is active

Vendor and admin portals

  • Body 14/20, table 13/18, page title 22/28, section title 18/24
  • Tables use tabular figures and right-align numbers
  • Mobile text scales up to 130% without clipping; test at 200%

Space, shape and depth

Why it looks like this

  • Cream on near-black is 17.5:1; the muted line is 10:1. Both stay legible in direct sun.
  • The only orange is the action, so the eye lands on the button.
  • Preset messages replace typing (E16-US4). The same actions are available by voice.
  • Large type and one button keep glance time short while riding.

Accessibility and content

Targets the team can test against in Chapter 4.

Rules

  • Body text at least 4.5:1; large text, icons, borders and focus rings at least 3:1.
  • Targets at least 48 × 48 dp; rider status buttons 64 dp.
  • State is never colour alone: icon plus word plus colour.
  • Every interactive element has a visible focus ring in orange-700 (light) or orange (dark).
  • Every icon-only button has a spoken label, for example "Remove item" or "Open assistant".
  • Layouts survive text at 130% and do not clip at 200%.
  • Motion is optional: with "reduce motion" on, sheets and the hold fill change instantly.
  • Lists of live updates (slots, ETA) announce changes to screen readers without moving focus.

Flutter: lib/theme/khaana_theme.dart

import 'package:flutter/material.dart';
import 'package:google_fonts/google_fonts.dart';

class KhaanaColors {
  static const orange = Color(0xFFF97316);
  static const charcoal = Color(0xFF242424);
  static const cream = Color(0xFFFFF8EF);
  static const orangeText = Color(0xFFC2410C);   // orange as text on light
  static const orangeTint = Color(0xFFFFEDD5);
  static const available = Color(0xFF15803D);
  static const limited = Color(0xFF854D0E);
  static const full = Color(0xFFB91C1C);
  static const closed = Color(0xFF57534E);
  static const info = Color(0xFF0369A1);
}

ThemeData khaanaTheme(Brightness b) {
  final dark = b == Brightness.dark;
  final scheme = ColorScheme(
    brightness: b,
    primary: KhaanaColors.orange,
    onPrimary: KhaanaColors.charcoal,            // never white on orange
    primaryContainer: dark ? const Color(0xFF3A2415) : KhaanaColors.orangeTint,
    onPrimaryContainer: dark ? const Color(0xFFFDBA74) : const Color(0xFF7C2D12),
    secondary: dark ? KhaanaColors.cream : KhaanaColors.charcoal,
    onSecondary: dark ? KhaanaColors.charcoal : KhaanaColors.cream,
    error: dark ? const Color(0xFFF87171) : KhaanaColors.full,
    onError: dark ? KhaanaColors.charcoal : Colors.white,
    surface: dark ? KhaanaColors.charcoal : Colors.white,
    onSurface: dark ? KhaanaColors.cream : KhaanaColors.charcoal,
    outline: dark ? const Color(0xFF8C8379) : const Color(0xFF8A7F73),
    outlineVariant: dark ? const Color(0xFF3A3835) : const Color(0xFFEADBC8),
  );
  final base = ThemeData(useMaterial3: true, colorScheme: scheme);
  return base.copyWith(
    scaffoldBackgroundColor: dark ? const Color(0xFF1A1A1A) : KhaanaColors.cream,
    textTheme: GoogleFonts.plusJakartaSansTextTheme(base.textTheme),
    filledButtonTheme: FilledButtonThemeData(
      style: FilledButton.styleFrom(
        minimumSize: const Size.fromHeight(56),
        shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
        textStyle: const TextStyle(fontSize: 16, fontWeight: FontWeight.w700),
      ),
    ),
    inputDecorationTheme: InputDecorationTheme(
      border: OutlineInputBorder(borderRadius: BorderRadius.circular(12)),
      contentPadding: const EdgeInsets.symmetric(horizontal: 14, vertical: 14),
    ),
    cardTheme: CardThemeData(
      elevation: 0,
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(16),
        side: BorderSide(color: scheme.outlineVariant),
      ),
    ),
  );
}
